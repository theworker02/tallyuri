# tallyuri

Tally structured JSON uri payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/tallyuri/

## Install / run

```bash
git clone https://github.com/theworker02/tallyuri.git
cd tallyuri
node src/cli.js
node --test
```
